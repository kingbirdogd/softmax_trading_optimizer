Mean-Reversion Softmax Trading Workflow

這份報告說明的是你現在的核心思路：每天收盤後更新模型，下一個交易日用模型交易，並且避免 leakage。 這本質上是 rolling walk-forward training，適合跨期、價差、均值回歸類產品。

適用範圍： 這套模型只適合多腿套利 / 價差 / basis / cross-contract mean-reversion標的，並且要求它們根本不太可能長期保持明顯方向性趨勢。它不是通用型方向性交易模型，也不適合單腿、持續向上或向下趨勢的產品。

核心假設

回歸型策略

不是直接預測漲跌，而是預測偏離公平價的程度，以及回歸風險。

訓練方式

Walk-forward

每天晚上收市後訓練，第二天用訓練後模型進行交易。

兩個中間目標

Fair + Risk

一個估計公平價，另一個估計風險/波動/偏離強度。

最終目標

PnL / RR

最後看的是風險調整後收益，而不是單純方向正確率。

1. 核心思想：每天晚上訓練，第二天交易

1
收盤後整理當天資料 把當天 tick、spread、basis、volatility、rolling statistics 都存起來。將當天資料加進最近 30 天歷史窗。
2
訓練 fair-price model 使用今天和前 30 天資料，擬合“下一個交易日開市後第 31 口”的公平價 / 公平價差。這是均值回歸交易的基礎。
3
訓練 risk model 再用相同資料訓練“下一個交易日第 31 口的風險 / 波動 / 偏離強度”。這決定通道寬度、門檻大小、是否加倉。
4
凍結模型參數 這些模型參數在下一個交易日使用前固定，不再回頭看當天/下一天的資料。這是避免偷看的關鍵。
5
下一交易日使用模型交易 根據 fair-price 和 risk 計算偏離 signal，判斷是否進場、加倉或平倉。
這個流程的本質是：今天收盤後訓模型，明天用模型交易。換句話說，模型永遠看不到未來資料。

2. 你的訓練目標是什麼？

中間目標 1：Fair Price / Fair Spread

  • 目標是預測下一個交易日開市後第 31 口的合理價
  • 這可以看作公平價、便宜/昂貴程度、basis、spread、ratio
  • 如果當前價偏離公平價太大，表示有均值回歸機會

中間目標 2：Risk / Volatility

  • 目標是預測風險程度、波動大小、偏離強度
  • 這決定通道寬度、加倉門檻、交易規模
  • 較高風險意味著要更保守，較低風險可以更放大

中間目標 3：X1 / X2（策略門檻）

這是你真正談到的最重要策略層目標：X1 是開始交易的偏離門檻，X2 是加倉的再偏離門檻。
它不是單純一個 random hyperparameter，而是“交易偏離程度的學習結果”。

  • X1：進場門檻，偏離公平價多大時開始進場
  • X2：加倉門檻，已持倉下再偏離多少才加碼
  • 這兩個值要和 risk model 配合，不能單獨看成固定常數
要注意： 目前很多 AI 只做成「grid search X1/X2」或「手工設定 X1/X2」，這不等於真正訓練了 X1 / X2； 真正的訓練應該是：根據當天/前 30 天資料，在收盤後學出下一個交易日的門檻值，再在下一個交易日使用。

3. 最終目標：不是預測方向，而是風險調整後收益

你真正想要的最終訓練目標，不是「價格會漲還是跌」，而是：

  • maximize net PnL
  • or maximize PnL - λ × drawdown
  • 並考慮 fees、slippage、spread、滑點、持倉成本
公平價估計 風險估計 X1 / X2 門檻 風險調整收益

4. 這個流程為什麼不偷看？

  1. 訓練資料只包含「今天 + 前 30 天」
  2. 目標是「下一個交易日第 31 口」
  3. 交易使用的是「當天收盤後固定住的模型」
  4. 下一天的實際行情不會反過來被拿來訓練同一輪模型
  5. 這是 out-of-sample / walk-forward 的正確做法
如果你在 day t 內用 day t+1 的 tick 去訓練，那就是 leakage；如果你在 day t 收盤後做模型，並且只用 day t 前的資料訓練， 那就符合你真正想要的交易流程。

5. 實際日運作流程（上線版本）

A
交易日收盤後：盤後更新 收集今日所有 tick、spread、basis、volume、execution 信息，加入歷史窗。
B
盤後訓練 用當天 + 前 30 天資料，更新 fair-price model 和 risk model。訓練目標是下一個交易日開市後第 31 口的 fitting target。
C
固定模型參數 這些參數在下一個交易日內不再變動，保證“白天交易”使用的是已完成的 model snapshot。
D
下一交易日開盤：用模型計算 signal 計算 fair_price、risk、deviation、z-score，根據 X1 / X2 / band 判定 entry / add / exit。
E
交易日中持倉管理 若偏離持續加大，可能加倉；若接近均值、或風險升高，則縮倉或平倉。
F
收盤後再回到 A 交易結果記錄進 PnL、drawdown、trade log，供下一輪訓練使用。

6. 如果要把這個思想寫成實際規則，最重要的 6 點

  1. 公平價模型：只看到今天和前 30 天的資料
  2. 風險模型：只看到今天和前 30 天的風險統計
  3. 目標是下一個交易日的第 31 口，而不是整天
  4. 交易使用模型參數，而不是當天 re-fit
  5. X1 / X2 是策略門檻，需要與 risk 配合調整
  6. 最終判斷標準是 net PnL / drawdown / fee-adjusted return

7. Softmax 估計器的完整數學形式

這個系統的核心學習單元是 softmax-weighted regressor，幾乎所有的 fair-price 與 risk 估計都來自同樣的結構：

Softmax wi = ezi∑k ezk
Output ŷ = ∑i wixi

其中：

  • z 是每個特徵的 logit
  • wi 是 softmax 權重，保證總和為 1
  • xi 是特徵值
  • ŷ 是預測值

若訓練目標是 y，則損失函數為：

Loss L = 1N ∑t (ŷt - yt)2

對 logit zj 的偏導可寫成：

Grad ∂ŷ∂zj = wj(xj - ŷ)

因此使用 Adam 更新時，可計算梯度 gj = ∂L∂zj，並做：

Adam mj ← β1mj + (1 - β1)gj
vj ← β2vj + (1 - β2)gj2
\hat{m}j = mj1 - β1t
\hat{v}j = vj1 - β2t
zj ← zj - η · \hat{m}j√{\hat{v}j} + ε

這就是模型在收盤後訓練時，對公平價與風險估計做最小平方回歸的本質。

8. Fair-value 模型的數學定義

公平價模型不是預測漲跌，而是在當前市場狀態下預測一個「合理價」或「基準價」。它的特徵向量通常是：

Feature xFt = [μt-1, μt-2, ..., μt-K, ppreopen1, ..., ppreopenM]

這裡：

  • μt-k 是最近歷史的均值或基準量
  • ppreopenm 是盤前資訊特徵
  • K, M 由配置決定，可在滾動窗中調整

預測值為：

Fair ŷfair = ∑i wixi

在交易規則中，偏離程度通常被定義為：

Dev dev = price - fair_value

當 dev 很大時，顯示市場價格離公平價足夠遠，可能出現均值回歸機會；當 dev 很小時，則市場更接近均衡狀態。

9. Risk 模型的數學定義

Risk 模型用來估計「接下來這個交易日，偏離公平價多大尺度是合理的」。這一層非常重要，因為它不只是「預測價格」，而是預測「市場允許多少偏離」。

Feature xRt = [σprice, μspread, σspread, σintra, μintra spread, σintra spread]
Risk ŷrisk = max(0, ∑i wixi)

其中：

  • σprice 是價格波動率
  • μspread 是價差均值
  • σspread 是價差波動
  • σintra 是盤中波動程度

風險帶的實際上下界可以寫成：

Band upper = fair + fee_ticks + risk
lower = fair - fee_ticks - risk

這表示在上下界之外才考慮進場與加倉，避免在微小偏離時過度交易。

10. 滾動回饋與 X1 / X2 的更新理由

這個模型最重要的地方，是把交易結果當作下一輪訓練信號，而不是把一個固定設定當成永遠有效的常數。

當天的交易結果可以被壓縮成一個 feedback vector：

State ft = [avg_realized, avg_floating, avg_total, avg_net, avg_drawdown, avg_opportunity, avg_signal_strength, avg_win_rate, avg_exposure]

使用最近 N 天的回饋，可更新策略參數：

Update if avg_total > 0 and drawdown small: x1, x2 = x1(1 + α), x2(1 + α)
else if win_rate low or drawdown high: x1, x2 = x1(1 - β), x2(1 - β)

也就是：如果交易最近表現良好，則容忍更大偏離去加倉；如果最近輸掉太多，則更保守、縮小門檻，降低過度加碼的風險。

X1 / X2 不是固定超參數，而是上一輪表現下的策略種子參數；它們會在每一輪 rolling training 中更新。

11. 複雜度與 slow-update（慢速調整層）

第二層 slow-update 的理念是：不是每個 day 都用大小調整策略，而是當整體市場 regime 發生變化時，慢慢調整特徵窗口大小與門檻。

例如設定窗口為：

Window windownew = clamp(windowold + step · regime_score, min_window, max_window)

其中 regime_score 可從最近幾日的 win rate, net PnL, drawdown, exposure, signal strength 組合：

Score score = α · total_pnl_norm + β · win_rate - γ · drawdown - δ · poor_signal_ratio

這樣的設計有三個好處：

  • 避免單日噪音導致窗口大幅振盪
  • 當市場更平穩時可以擴大窗口、降低噪音
  • 當市場更劇烈時可以縮小窗口、提高敏感度

因此，整個系統其實是「快層 + 慢層」雙層適應：快層處理日內/日與日之間的交易門檻，慢層處理窗口大小與整體 regime。

12. 為什麼這個 rolling training 是正確的？

  1. 市場不穩定，regime 會變化：固定 60 天如果市場轉型，就會變得過時。
  2. 均值回歸最相關的資訊在最近歷史：最近的價差與波動代表當前市場狀態，更能反映現階段的回歸強度。
  3. 交易結果是最直接的 reward signal：如果模型今天不好，下一輪應該不再用完全相同設定；這是 online learning 的本質。
  4. no leakage 是不可少的：訓練永遠只能看到截至 day t 的資訊，交易永遠使用 day t 收盤後凍結的模型，不可看 day t+1 的資料。
這些設計的核心目標不是「猜對方向」，而是：在每一天都根據上一次交易的真實結果更新下一次的均值回歸門檻與風險判定。 這就是 rolling walk-forward mean-reversion training 的本質。

13. 最後一句話

你的模型核心其實是：每天收盤後學出下一個交易日的公平價和風險，再在下一個交易日用它做均值回歸交易。 這個流程是正確的，而且非常符合“跨期、spread、可回歸產品”的交易邏輯。
真正需要補強的是：把 X1 / X2 做成可訓練/可優化的策略參數，而不只是固定搜索值。
